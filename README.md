# RAG
Rag (Retrieval Augmented Generation) Python solution with llama3, LangChain, Ollama, and ChromaDB in a Flask API-based solution



# installation
Run this code first

```shell
git clone git@github.com:Lucifer516-sudoer/embedding_with_rag.git
cd embedding_with_rag
poetry install
poetry shell
fastapi dev --port 8080 app.py
```

then open another terminal and run this
```shell
streamlit run st_ui.py
```
